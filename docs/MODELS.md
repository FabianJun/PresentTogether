# A practical model choice

For designing the activity, implementing it and checking its rules, start with a **capable everyday coding model and High reasoning effort**. This is our starting recommendation for this task, not a requirement to use the largest or most expensive model.

| Provider | Example | Suggested starting setting |
|---|---|---|
| OpenAI | GPT-6.1 Sol in a coding agent that offers it | High reasoning effort. [Model details](https://developers.openai.com/api/docs/models/gpt-6.1-sol) |
| Anthropic | Claude Opus in a coding agent that offers it | High effort for the initial build and tricky game logic. Sonnet is another option when usage or speed matters. [Model comparison](https://platform.claude.com/docs/en/models/overview), [effort settings](https://platform.claude.com/docs/en/build-with-claude/effort) |

Reasoning effort is how much work the model can put into planning and checking. Higher effort may take longer and use more of your allowance. You can lower it for a small wording change. Leave maximum settings off unless the normal setup is struggling with a specific problem.

The agent should help you find the equivalent setting in your tool. Available models and controls depend on the product, account and plan; an API model listing does not establish subscription access. [OpenAI's model-selection controls](https://learn.chatgpt.com/docs/models?surface=cli) explain this distinction.

Model names and prices change. These examples were checked on 14 November 2026. Ask your agent to verify the current options, access and cost before buying a plan. You do not need an AI model running inside this classroom game: the agent builds the application, then the app runs on its own.
